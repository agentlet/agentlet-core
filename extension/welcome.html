Agentlet core extension

An experimental extension that runs agentlet core on the tab you choose, only when you ask. It is not published on any extension store.

What it does

Runs agentlet core on one tab

Loads the same side panel and APIs as the bookmarklet, on the current tab, when you activate it.

No standing access to sites

The extension has no host permissions and no script running on your pages. It can touch a tab only after you click or press the shortcut, and only until you navigate away.

Only bundled modules

Modules run only if they ship inside the extension package. The extension never downloads or runs code from a URL.

Getting started

1

Open a website

Open the page where you want to use agentlet core.

2

Open the popup

Click the extension icon in the browser toolbar, or press Ctrl+Shift+A (Command+Shift+A on a Mac) to skip the popup.

3

Activate on this page

Click "Activate on this page" to start agentlet core in the current tab. Click it again to show or hide the panel.

4

Activate again after a reload

Agentlet core does not start by itself. After you navigate or reload, activate it again.
