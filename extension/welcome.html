Agentlet core extension

An experimental extension that injects agentlet core into the pages you choose. It is not published on any extension store.

Get started

What it does

Injects agentlet core

Loads the same side panel and APIs as the bookmarklet, on the current tab, when you activate it.

Runs your modules

Modules register for URL patterns and appear in the panel on matching pages.

Optional AI assistant

Sends your prompt to the AI provider you configure with OPENAI_API_KEY. Nothing is sent otherwise.

Getting started

1

Open a website

Open the page where you want to use agentlet core.

2

Click the extension icon

Click the extension icon in the browser toolbar, or press Ctrl+Shift+A.

3

Activate on the page

Click "Activate on page" to inject agentlet core into the current tab.

4

Use your modules

Use the modules that match the page, and the AI assistant if you configured a provider.

Settings
