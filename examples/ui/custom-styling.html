Custom styling

This example demonstrates dynamic theme switching capabilities using Agentlet Core's theming system with iconic design styles.

What this example shows:

  • Dynamic theme switching between iconic design systems
  • Glass transparent theme with blur effects
  • Material Design bold colors and elevation
  • VS Code Dark developer-focused dark theme
  • Real-time agentlet panel appearance changes

Theme selection

Theme switching API examples:

Theming through the shadow root with CSS variables

// This example toggles a body class; the CSS custom properties
// defined for that class (see the <style> block above) inherit
// through the shadow boundary into the panel, no JS API call needed.
document.body.classList.add('theme-vscode');
document.body.classList.remove('theme-glass', 'theme-material', 'theme-tux');

Updating the theme from JavaScript

// Merge new values into the current theme...
window.agentlet.themeManager.updateTheme({
    backgroundColor: '#1E1E1E',
    headerBackground: '#2D2D30',
    textColor: '#CCCCCC'
});

// ...then regenerate the panel's stylesheet to apply them
window.agentlet.ui.regenerateStyles();
