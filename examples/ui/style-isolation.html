Style isolation

This page has deliberately hostile CSS: a global reset, a page-wide Comic Sans font and purple text color, and aggressive rules for h3, button, input and div. With shadowDom enabled (the default), none of it reaches the agentlet panel, and the panel's own CSS does not leak back into the page either.

What this example shows:

  • The host page's hostile CSS does not reach the panel, its content, or its dialogs
  • The panel's own CSS does not leak out into the host page
  • document.getElementById('agentlet-container') finds nothing; window.agentlet.ui.query(...) does
  • The same page also offers a shadowDom: false button, for comparison

The shadowDom option:

const agentlet = new AgentletCore({
    shadowDom: true // default: panel, dialogs and toasts mount in a shadow root
});

// Reach into the panel from JavaScript regardless of shadowDom:
const panel = window.agentlet.ui.query('#agentlet-container');
const allButtons = window.agentlet.ui.queryAll('button');

See docs/shadow-dom.md for what is and isn't isolated, and why.
