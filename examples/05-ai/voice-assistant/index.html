🤖 Voice Assistant Demo - Agentlet Core

This advanced example demonstrates a complete voice assistant using speech-to-text, AI processing, and text-to-speech in a seamless workflow.

What this example shows:

  • Keyboard shortcut integration (Ctrl+; to activate voice assistant)
  • Command prompt dialog for voice input
  • Speech-to-text for question capture
  • AI processing via OpenAI API
  • Fullscreen dialog for AI response display
  • Text-to-speech for AI response playback
  • Complete voice interaction workflow

🎯 How to use:

  1. Initialize Agentlet Core and configure your OpenAI API key
  2. Press Ctrl + ; anywhere on the page to activate voice assistant
  3. Speak your question when prompted
  4. Wait for AI processing and response
  5. View the response in fullscreen and optionally listen to it

Shortcut Registration

// Register Ctrl+; shortcut
window.agentlet.utils.shortcuts.register('ctrl+;', async () => {
    await activateVoiceAssistant();
});

// Check available shortcuts
console.log('Registered shortcuts:', window.agentlet.utils.shortcuts.list());

Voice Input Dialog

// Show command prompt for voice input
const result = await window.agentlet.utils.Dialog.commandPrompt({
    title: 'Voice Assistant',
    message: 'Speak your question...',
    showMicrophone: true,
    speechOptions: {
        language: 'en-US',
        continuous: true
    }
});

console.log('Voice input:', result.text);

AI Processing

// Send question to AI
const aiResponse = await window.agentlet.ai.sendPrompt(
    `Please answer this question clearly and helpfully: ${question}`,
    [], // no images
    { 
        model: 'gpt-4o-mini',
        maxTokens: 1000 
    }
);

console.log('AI Response:', aiResponse);
