🎤 Speech-to-Text Demo - Agentlet Core

This example demonstrates speech-to-text functionality using browser's native SpeechRecognition API with OpenAI Whisper fallback.

What this example shows:

  • Browser-first speech recognition (free, offline, privacy-friendly)
  • OpenAI Whisper API fallback (better accuracy, requires API key)
  • Real-time transcription with interim results
  • Language selection and voice command recognition
  • Event handling for speech recognition states

Basic Usage

// Start listening with default settings
await window.agentlet.speech.startListening();

// Listen for results
window.agentlet.speech.onSpeechEvent('result', (data) => {
    const transcript = data.results[0].transcript;
    const isFinal = data.results[0].isFinal;
    console.log('Transcript:', transcript, 'Final:', isFinal);
});

// Stop listening  
window.agentlet.speech.stopListening();

Advanced Configuration

// Start with custom options
await window.agentlet.speech.startListening({
    language: 'es-ES',
    continuous: true,
    interimResults: true,
    apiProvider: 'browser' // or 'openai' or 'auto'
});

// Check status
const status = window.agentlet.speech.getStatus();
console.log('Speech capabilities:', status);

Event Handling

// Listen for various events
window.agentlet.speech.onSpeechEvent('start', () => {
    console.log('Started listening');
});

window.agentlet.speech.onSpeechEvent('end', () => {
    console.log('Stopped listening');
});

window.agentlet.speech.onSpeechEvent('error', (data) => {
    console.error('Speech error:', data.error);
});
