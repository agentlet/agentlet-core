🔊 Text-to-Speech Demo - Agentlet Core

This example demonstrates text-to-speech functionality using browser's native SpeechSynthesis API with ElevenLabs and OpenAI TTS fallbacks.

What this example shows:

  • Browser-first speech synthesis (free, offline, privacy-friendly)
  • ElevenLabs API for premium voice quality (requires API key)
  • OpenAI TTS API fallback (good quality, requires API key)
  • Voice selection and speech parameter control
  • Real-time speech control (pause, resume, stop)

Basic Usage

// Speak text with default settings
await window.agentlet.speech.speak("Hello world!");

// Check if currently speaking
const isSpeaking = window.agentlet.speech.isSpeaking();

// Stop current speech
window.agentlet.speech.stopSpeaking();

Advanced Configuration

// Speak with custom options
await window.agentlet.speech.speak("Hello world!", {
    provider: 'elevenlabs', // or 'openai', 'browser', 'auto'
    rate: 1.2,
    pitch: 0.8,
    volume: 0.9,
    language: 'en-US'
});

// Use specific voice
await window.agentlet.speech.speak("Bonjour!", {
    provider: 'browser',
    voice: 'Google français'
});

Voice Management

// Get available voices
const browserVoices = window.agentlet.speech.getAvailableVoices('browser');
const elevenLabsVoices = window.agentlet.speech.getAvailableVoices('elevenlabs');
const openaiVoices = window.agentlet.speech.getAvailableVoices('openai');

// Find best voice for language
const bestVoice = window.agentlet.speech.findBestVoice('es-ES', 'browser');
console.log('Best Spanish voice:', bestVoice);
