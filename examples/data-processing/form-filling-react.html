Fill a React controlled form

A React controlled input keeps its value in useState and ignores a plain element.value = x assignment: React tracks what it last rendered through its own property descriptor on the DOM node, so the assignment is absorbed by that tracker instead of reaching the real input. window.agentlet.forms.fill() writes through the native prototype setter instead, the same way a real keystroke does, so React's change detection sees it.

What this example shows

  • A form built with React 18 (no build step, React.createElement) where every field is controlled by useState
  • The React state printed live as JSON, so a fill can be verified without inspecting the DOM
  • A naive fill (plain DOM assignment, dispatching input/change manually) that leaves the React state untouched
  • window.agentlet.forms.fill() filling the same fields correctly, updating the React state

// Fill the controlled fields; the native prototype setter is used
// under the hood so React's change detection sees the new values.
const form = document.getElementById('reactControlledForm');
const result = window.agentlet.forms.fill(form, {
    '#reactName': 'Jordan Rivers',
    '#reactBio': 'Loves testing controlled forms.',
    '#reactRating': 'gold',
    '#reactSubscribe': true
});
