Records copy and paste

Copy structured data from one place and paste it into a form that uses different field names. window.agentlet.records writes a record to the system clipboard. On the target, it matches the record to the form, shows a preview, then fills it. Nothing is submitted.

What this example shows

  • Creating a record from a card, a table, or an element you pick on the page
  • Copying it in several clipboard formats at once
  • Matching record fields to a form whose names differ, including a French label and a select
  • A preview dialog before anything is filled
  • Smart paste with onPaste(), and a "Paste record" button with pasteFromClipboard()

How to try it

  1. Click "Initialize agentlet core".
  2. Click "Copy company", or "Pick an element" and click the card.
  3. Click in a field of the target form and press Ctrl+V (Cmd+V on a Mac). The preview opens. Press Fill.
  4. Or click "Paste record", which reads the clipboard from the click. Use it where paste events are blocked.
  5. Change a mapping in the preview. The next paste of the same record type into this form remembers it.

The password field is never filled, and a password is never copied. The clipboard can be read by other applications, so never copy secrets.

Records API reference

Source page

const record = window.agentlet.records.fromElement(card, { type: 'organization' });
await window.agentlet.records.copy(record);

Target page

window.agentlet.records.onPaste(async ([record]) => {
    const result = await window.agentlet.records.fill(record, form);
    if (result.confirmed) {
        console.log(`${result.successful} fields filled`);
    }
}, { scope: form, types: ['organization'] });

// Fallback from a click, for pages that block paste events
await window.agentlet.records.pasteFromClipboard(form, { types: ['organization'] });
