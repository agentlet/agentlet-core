Mount API: plain DOM

The core ships no UI framework of its own. Each agentlet mounts whatever it wants into the container the core hands it through mount(container, context). This example builds its content with plain DOM APIs and keeps its state on the module instance, not in the DOM, so a remount does not lose it.

What this example shows:

  • Overriding mount(container, context) to build DOM imperatively
  • Overriding unmount(container) to remove the listeners mount() added
  • Keeping state (this.count) on the module instance so it survives a remount
  • Reading context.trigger to show why the last mount happened
  • Injecting scoped CSS with this.injectStyles() once per module

Module source

class MountVanillaModule extends window.agentlet.Module {
    constructor() {
        super({
            name: 'mount-vanilla-demo',
            patterns: ['localhost'],
            description: 'Mount API demo built with plain DOM APIs'
        });
        this.count = 0;
        this._stylesInjected = false;
    }

    async mount(container, context) {
        // Build the counter with plain DOM APIs.
        const wrapper = document.createElement('div');
        wrapper.className = 'mount-vanilla-counter';
        // ...append count label, +1 / reset buttons, trigger label...
        container.appendChild(wrapper);

        this._plusHandler = () => { this.count++; /* update label */ };
        this._resetHandler = () => { this.count = 0; /* update label */ };
        plusBtn.addEventListener('click', this._plusHandler);
        resetBtn.addEventListener('click', this._resetHandler);

        if (!this._stylesInjected) {
            this.injectStyles('.mount-vanilla-counter { ... }');
            this._stylesInjected = true;
        }
    }

    async unmount(container) {
        // Remove exactly what mount() added.
        plusBtn.removeEventListener('click', this._plusHandler);
        resetBtn.removeEventListener('click', this._resetHandler);
    }
}

State retention

Clicking "Refresh panel content" calls window.agentlet.refreshContent(), which unmounts and remounts the active module with context.trigger === 'refresh'. The counter keeps its value across that cycle because it is read from this.count on the module instance when mount() rebuilds the DOM, not from the DOM itself.
