Deployment modes comparison

This example demonstrates the difference between registry mode (traditional) and packaged mode (CORS-free) deployment of Agentlet Core.

Key differences:

Feature Registry Mode Packaged Mode
CORS issues ❌ Can occur with JSON fetch ✅ Never - script injection only
Loading method Fetch agentlets-registry.json Sequential script loading
Module loading Individual module scripts Pre-bundled module pack
Deployment complexity Requires proper CORS setup ✅ Works on any CDN/server
Performance Dynamic module selection ✅ All modules pre-bundled

Registry Mode Traditional CORS Risk

The traditional deployment mode that dynamically loads modules from a registry JSON file. This is the original approach.

How it works:

  1. Load AgentletCore script
  2. Fetch agentlets-registry.json (CORS required)
  3. Parse registry and load individual module scripts
  4. Register modules dynamically

Configuration:

// Configure registry mode
window.agentletConfig = {
    debugMode: true,
    registryUrl: 'https://cdn.example.com/agentlets-registry.json'
};

// Load core script
const script = document.createElement('script');
script.src = 'path/to/agentlet-core.js';
script.onload = () => {
    const agentlet = new window.AgentletCore.default(window.agentletConfig);
    agentlet.init(); // Will fetch registry and load modules
};
document.head.appendChild(script);

Pros:

  • ✅ Flexible module selection
  • ✅ Smaller initial download
  • ✅ Dynamic module discovery

Cons:

  • ❌ CORS issues with JSON fetch
  • ❌ Requires proper server headers
  • ❌ Multiple network requests

Packaged Mode CORS-Free No CORS Issues

The new deployment mode that avoids CORS issues by using sequential script loading instead of JSON fetch. Perfect for CDN deployment.

How it works:

  1. Light bookmarklet injects core bundle
  2. Core bundle automatically loads module bundle
  3. Modules self-register when loaded
  4. No JSON fetch - only script injection

Configuration:

// Configure packaged mode
window.agentletConfig = {
    deploymentMode: 'packaged',
    baseUrl: 'https://cdn.example.com/agentlet/',
    coreUrl: 'https://cdn.example.com/agentlet/agentlet-core-packaged.js',
    moduleUrl: 'https://cdn.example.com/agentlet/agentlet-modules.js',
    debugMode: true
};

// Load packaged core (includes modules automatically)
const script = document.createElement('script');
script.src = window.agentletConfig.coreUrl;
script.onload = () => {
    // Core will auto-initialize in packaged mode
    // Modules are loaded automatically via script injection
};
document.head.appendChild(script);

Build artifacts:

  • agentlet-core-packaged.js - Core with packaged mode
  • agentlet-modules.js - All modules bundled
  • bookmarklet-packaged-optimized.js - Ultra-light injector

Pros:

  • ✅ No CORS issues ever
  • ✅ Works on any CDN/server
  • ✅ Faster loading (pre-bundled)
  • ✅ Ultra-light bookmarklet (941 bytes)

Cons:

  • ⚠️ All modules included (larger bundle)
  • ⚠️ Less flexible than registry mode
